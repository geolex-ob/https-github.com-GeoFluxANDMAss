Программа по расчету инструмента в жидкости.                                                                                                                
Расчеты ГТИ. Версия 0.1.4                                                                                                                             
Под Linux нет нативных приложений, или я просто не нашел:)                                                                                               
                                                                                                                                       
                                                                                                                                                           
                                                                                                                                                           
В программе реализован справочник КНБК, расчет веса колонны инструмента, времени циркуляции (циркуляция может быть обратной, вдруг вы на КРС или испытаниях). Программа запоминает последние КНБК и введенные данные в разделе информации для расчетов.
