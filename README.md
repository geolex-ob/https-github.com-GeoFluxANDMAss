Программа по расчету инструмента в жидкости.                                                                                                                
Расчеты ГТИ. Версия 0.2.0                                                                                                                            
Под Linux нет нативных приложений, или я просто не нашел:)                                                                                               
                                                                                                                                       
                                                                                                                                                           
                                                                                                                                                           
В программе реализован справочник КНБК, расчет веса колонны инструмента, времени циркуляции (циркуляция может быть обратной, вдруг вы на КРС или испытаниях). Программа запоминает последние КНБК и введенные данные в разделе информации для расчетов. Для упрощения расчетов в программе есть автоматический расчет длины для выбранного элемента (расчет осуществляется вычетом остальных элементов от глубины спуска).                                                                                                                      
                                                                              
                                                                          
0.1.5 - Добавлена возможность расчета жидкости в цилиндрической емкости лежащей на боку.                                                                                    
                                                                                                       
                                                                                    
0.2.0 - Добавлена возможность рассчитать вес инструмента при проведении ИПТ (внутри инструмента другая жидкость и не полное его заполнение)
